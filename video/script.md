## 段落 1 · 这是什么（约 20s）

1. GitHub 上的这个项目叫 glmate，是一个把 AI 接入 QQ 群的小工具。
2. 在群里 @ 它，可以聊天、识别图片里的文字、生成图片、生成视频，也可以先联网搜索再回答。
3. 模型默认接智谱开放平台，几个都用免费额度那一档。
4. 项目以 MIT 协议开源。

## 段落 2 · 结构（约 30s）

5. 它的结构是三层。
6. 最下层是 QQ 协议端 SnowLuma。它不自己登录 QQ，而是注入到已经登录的 QQ 桌面进程里，接管这个账号的收发消息，然后对外提供 OneBot v11 接口。
7. 中间是 glmate，一个 Python 程序，连上 OneBot 的 WebSocket 端口，把群消息转成模型调用。
8. 最上层是模型的 API 地址。
9. 整条链路没有第三方服务器，消息只从自己这台机器过一遍。
10. 所以使用顺序是固定的：先把 QQ 小号登录到桌面客户端，再启动协议端注入，最后起机器人。

## 段落 3 · 部署方式：交给 AI agent（约 40s）

11. 部署是这个项目的主要设计目标，它假定操作者不是人，而是 AI 编程助手。
12. 用法是把仓库地址发给 agent，让它读完 README 之后自己执行。
13. README 按可被机器执行的顺序写：前置条件、依赖安装、配置字段对照表、启动协议端、启动机器人、验证。
14. 每个配置字段的含义、取值来源、填错之后的现象，列在同一张表里。
15. 文档里也写了几个必然会踩的点。依赖清单在 `zglmbot/requirements.txt`，仓库根目录那一份只是转发。协议端配置文件里有两个 accessToken，分别给 HTTP 和 WebSocket 用，要填的是 WebSocket 那一个。
16. 机器人只有两个第三方依赖，一个负责连 WebSocket，一个负责搜索，其余全部用标准库。
17. 协议端可以完全无窗口后台启动，改配置之后按命令行特征重启，不需要人盯着控制台。
18. 整个流程里真正需要人做的只有一件事：把那个 QQ 小号登录到桌面客户端。

## 段落 4 · 出错时的处理（约 28s）

19. 起不来的情况也交给 agent，README 末尾按阶段列了故障表。
20. 端口连不上，是协议端还没起来或者账号没登录，端口根本没监听。
21. 返回 401，是两边 token 不一致，重新解压协议端之后必然出现，重新取值写进配置、重启机器人就好。
22. 管理页能打开但机器人连不上，多半是协议端起了两个实例，端口会往后漂一个。
23. 日志分别存在机器人的 `state/zglmbot.log` 和协议端的 `logs/` 下，把报错交回给 agent，它可以定位到具体代码位置。
24. 机器人的核心实现是一个约一千两百行的 Python 文件，单个文件就能完整读进上下文，改配置还是改逻辑都可以由 agent 完成。

## 段落 5 · 端点与模型（约 25s）

25. 对话和图片识别走标准的 OpenAI 兼容接口，把地址换成 DeepSeek、OpenRouter 或者本地推理服务都能连。
26. 只有画图和视频用的是智谱专有接口，换掉之后把这两个字段留空，对应能力会自动从可用列表里去掉，模型也不会假装自己画了图。
27. 备用模型不是必需的，留空就只用一个主模型，限流重试的十档全部打在同一个模型上。
28. 换端点时建议在 `contextWindows` 里补上模型的窗口大小，查不到的会按 128K 处理，压缩阈值会算偏。

## 段落 6 · 功能细节（约 25s）

29. 图片消息会自动做 OCR，不需要额外指令。
30. 生成图片和视频之后是以媒体形式发到群里，不是发一个链接。
31. 免费额度会限流，程序内置十档阶梯重试，总计约八十秒，重试期间不发群消息，全部耗尽才提示一次 429。
32. 上下文达到模型窗口的 80% 时，会把较早的消息压成摘要，最近三千 token 保持原文。
33. 每个群维护独立的会话树，用 /new、/rename、/use 切换，群与群之间互不影响。
34. /on 和 /off 由管理员使用，控制机器人是否响应。

## 段落 7 · 账号风险（约 20s）

35. 账号安全这一节建议不要跳过。
36. 这类第三方协议端不在腾讯的授权范围内，属于违反用户协议的灰色地带。
37. 实际表现通常是定期被踢下线，需要重新登录，少数情况会触发冻结，新号风险高于老号。
38. 因此建议：使用专门的小号，同一时间只开一个实例，消息间隔保持在两秒以上，只加入自己的白名单群。

## 段落 8 · 结尾（约 12s）

39. 项目地址是 github.com/m62m61m80bpzm2/glmate。
40. 需要准备三样东西：Python 3.10 以上、一个 API Key，以及一个 QQ 小号。
41. 然后把链接交给你的 AI 助手，README 就是写给它看的执行手册。
